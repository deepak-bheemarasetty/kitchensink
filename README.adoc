# Kitchen Sink

A Spring Boot REST API for registering and managing members. The application uses Java 21, Spring MVC, Spring Data JPA, Bean Validation, and an in-memory H2 database.

## Requirements

- JDK 21
- Maven 3.9 or later

## Run locally

```shell
mvn spring-boot:run
```

The API listens on `http://localhost:9080`. H2 runs in memory and is local to this application process; its data is reset when the application stops.

## API

List members:

```shell
curl http://localhost:9080/rest/members
```

Get a member:

```shell
curl http://localhost:9080/rest/members/1
```

Register a member:

```shell
curl -i -X POST http://localhost:9080/rest/members \
  -H 'Content-Type: application/json' \
  -d '{"name":"Jane Doe","email":"jane@example.com","phoneNumber":"2125551234"}'
```

The API returns `201 Created` for a successful registration, `400 Bad Request` for invalid input, `404 Not Found` when a member ID does not exist, and `409 Conflict` when the email is already registered.

## Tests

Run the JUnit 5 suite, which uses mocks and isolated in-memory H2 databases:

```shell
mvn test
```

## Build and run the executable JAR

```shell
mvn package
java -jar target/kitchensink.jar
```

## Configuration

Application settings are in `src/main/resources/application.properties`. The default HTTP port is `9080`; override it with `--server.port=...` or the `SERVER_PORT` environment variable.

The H2 console is available at `http://localhost:9080/h2-console` while the application is running. Use JDBC URL `jdbc:h2:mem:kitchensink`, username `sa`, and the configured password.
